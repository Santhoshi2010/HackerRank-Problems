# HackerRank-Problems
# 1.Plus Minus

## Problem

Given an array of integers, find the proportion of elements that are:

- Positive
- Negative
- Zero

Print each proportion with 6 digits after the decimal point.

## Example

Input:

[-4, 3, -9, 0, 4, 1]

There are:

- 3 positive numbers
- 2 negative numbers
- 1 zero
- 6 total numbers

## Calculation

Positive ratio:

3 / 6 = 0.500000

Negative ratio:

2 / 6 = 0.333333

Zero ratio:

1 / 6 = 0.166667

## Output

0.500000
0.333333
0.166667
